# W3-PM2 — NetworkWalks Password Cracking Tools

## Objective
Recover the password of the authorized NetworkWalks laboratory PDF using the NetworkWalks Hash Calculator and Password Cracker.

## Workflow
Protected PDF → Hash Calculator → PDF hash → Password Cracker → password → PDF verification

### Hash Calculator
The Hash Calculator reads the authorized protected PDF and produces a crackable PDF hash.

### Password Cracker
The Password Cracker tests candidate passwords from a dictionary or wordlist against the extracted hash.

### Verification
The recovered password is entered into the original laboratory PDF. Successful opening confirms the result.

## Safety
Only the instructor-provided laboratory PDF was used.

Do not publish the original PDF, complete hash, recovered password, credentials, or tokens.
