# NetworkWalks Password Cracker

## Purpose
The Password Cracker is used to test candidate passwords against the PDF hash produced by the Hash Calculator.

## Workflow
1. Open the Password Cracker.
2. Paste the authorized laboratory hash.
3. Select the available dictionary or wordlist.
4. Start the cracking process.
5. Wait for the matching password.
6. Verify the password against the original PDF.

The authorized laboratory password-recovery task was completed successfully.

The recovered password is intentionally excluded from this public repository.
