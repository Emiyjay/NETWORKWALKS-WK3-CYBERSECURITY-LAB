# NetworkWalks Hash Calculator

## Purpose
The Hash Calculator is used in the Week 3 laboratory to extract the password-verification hash from the authorized protected PDF.

## Workflow
1. Open the Hash Calculator.
2. Upload the laboratory PDF.
3. Generate the hash.
4. Confirm the expected PDF hash format.
5. Copy the hash locally for the next stage.

The extracted hash is sensitive laboratory material and is not stored in this public repository.
