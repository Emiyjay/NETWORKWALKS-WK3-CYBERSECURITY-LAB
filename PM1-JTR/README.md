# W3-PM1 — Password Cracking with John the Ripper

## Objective
Recover the password of the instructor-provided protected PDF using John the Ripper (JTR) and Johnny in an authorized educational environment.

## Workflow
1. Prepare the authorized protected PDF.
2. Extract the PDF password hash.
3. Save the hash in the required input format.
4. Load the hash into JTR/Johnny.
5. Start the password-recovery attack.
6. Observe the successful recovery.
7. Verify the recovered password against the laboratory PDF.

## Result
The authorized laboratory password-recovery task was completed successfully.

## Security
This module was performed only against the authorized lab file. No third-party accounts, systems, or credentials were targeted.

The recovered password and complete hash are intentionally not published in this public repository.
